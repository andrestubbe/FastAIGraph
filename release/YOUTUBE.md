Replace fuzzy, hallucination-prone text searches with structured, multi-hop relationship traversal in pure Java 17+.

FastAIGraph provides:
1. 🕸️ High-Speed In-Memory Graph (KnowledgeGraph): Sub-microsecond Node & Edge lookups.
2. 🔍 Multi-Hop BFS Sub-Graph Extraction: Traverses connected dependencies and entity structures.
3. 📄 Token-Efficient Prompt Context Serialization: Converts complex knowledge graphs directly into clean LLM-ready context.
4. ⚡ Zero External Dependencies: Pure Java 17, zero Neo4j/TinkerPop/database overhead.
